# 墙内：从信号到观念宇宙

> Behind the Wall: From Signal to the Universe of Ideas

一部关于认知本质的体系化论述。核心主张：所有智慧体的一切认知，皆源于对输入信号的加工重构，从未真正触碰过世界的本体实在。

## 内容结构

- `00_前言` —— 缘起与全书使命
- `01_第1章_引论` —— 问题、公理化方法与阅读导览
- `02_第2章_两条基础定义` —— 信号、智慧模型
- `03_第3章_命题一_信号怪物` —— 智慧无触碰本体的通道
- `04_第4章_命题二_双重筛选` —— 扰动 → 信号 → 意识
- `05_第5章_命题三_逻辑的局限` —— 自洽不等于真实
- `06_第6章_命题四_无法自证` —— 所有验证都在墙内
- `07_第7章_命题五_自我迭代` —— 思想可以改写解读规则
- `08_第8章_推论一_观念宇宙` —— 信号模式足以构建宇宙
- `09_第9章_推论二_文明认知隔绝` —— 不同的 f 展开不同的世界
- `10_第10章_自指检验` —— 本书如何对待自己
- `11_第11章_结语` —— 馈赠清醒、谦卑与自由

## 写作纪律

- 零本体预设：不押注外部世界是物质、模拟还是未知基底
- 不援引流派先贤，论证依靠体系内部逻辑
- 最少前提：两条基础定义起步，推导五条核心命题，收敛两条终极推论
